# docker-compose

## Setup

```bash
docker-compose up -d
```

## Frontend endpoing

<http://localhost:3000>

Надо зарегистровать компанию <localhost:3000/register>

Создать вакансию, заполнить данные

Нажать кнопку "Подробнее" у вакансии

В поисковой строке появится vacancy_id

Для начала собеседования кандидат переходит по <localhost:3000/invite/[vacancy_id]>
